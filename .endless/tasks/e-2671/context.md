CI run 44676626491 (Test, main, ubuntu-latest) fails examples/comprehensive TestRun: it expects 'CLI: <root>/home/.config/cfgstore-comprehensive' but Linux prints '<root>/appconfig/.config/cfgstore-comprehensive'. Two causes. (1) The test, added in E-2650, hard-codes the macOS layout; E-2650's verify ran only on macOS. (2) DirsProvider.CLIConfigDirType uses UserConfigDirFunc on Linux (os.UserConfigDir, already $XDG_CONFIG_HOME or ~/.config) and UserHomeDirFunc elsewhere, then always appends DotConfigPathSegment, so a real Linux CLI config resolves to ~/.config/.config/<slug>. Fixing (2) moves where existing Linux users' CLI configs are found. Also seen: cstest/dirs_provider.go hard-codes a 'Users' path segment, so cstest output differs on Linux. Reported by the E-2662 session.
