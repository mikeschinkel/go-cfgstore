mergeRootConfigs in config_stores.go calls Merge across the loaded layers and keeps the result in rc, then returns prc = rcMap[dirType]: the last layer as loaded, unmerged. Whenever more than one layer exists, the merge is computed and thrown away, so LoadDefaultConfig returns the project layer alone and every CLI-layer value is lost. Found from the endless project (task E-2300): a tmux.socket_dir in ~/.config/endless/config.json resolved correctly from a scratch directory but was ignored from any directory holding a .endless/config.json, while endless's own Merge, called directly, kept it. When this was written, layer merging had been deferred.
