Layer merging is part of the RootConfig interface: Merge(RootConfig) RootConfig, whose receiver is the higher-precedence layer and whose argument is everything merged below it. Merge returns the merged config as its receiver's own concrete type; a type embedding a config declares its own Merge, since the promoted one returns the embedded type. Loaders return the merge of every loaded layer, converted to the caller's type at runtime, because Go has no self type or covariant returns to promise that type in the signature. A Merge returning another type, or nil, fails loading rather than falling back to one layer. That is the loading path's one runtime type assertion, qualifying ADR 004. Rejected: a typed merge method on RootConfigPtr, which duplicates Merge under a second name and leaves RootConfig and RootConfigMap unable to describe a mergeable layer. Generic methods (Go 1.27) do not apply: interface methods cannot be generic or be implemented by generic methods.
