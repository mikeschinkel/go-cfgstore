ProjectConfigStoreExists(projectDir, configSlug, configFile) builds a project config store and calls SetConfigDir(projectDir), which sets the store's config dir itself, so it checks <projectDir>/<file> instead of <projectDir>/.<slug>/<file>. Called with a project directory, as the parameter name says, it returns false even when the project config exists. Passing the project's config dir (<projectDir>/.<slug>) works today, which is what examples/comprehensive does, with a comment, as of E-2650. A caller may already rely on that, so the fix changes behavior for them.
